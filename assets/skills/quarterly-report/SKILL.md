# 季度业务报告

## 何时用

用户的诉求命中以下任一关键词时加载本 skill：
"季度报告"、"QBR"、"经营回顾"、"OKR 复盘"、"营收分析"。

## 工作流

1. **先找数据，不要先写结论。** 用 `ls /data` 确认数据文件存在，
   再用 `read_file` 读取；缺数据就明确告诉用户缺哪一项，不要编造数字。
2. **交叉验证。** 同一指标在两个文件里出现且不一致时，停下来向用户确认。
3. **按五段式成稿**，写到 `/reports/{年份}Q{n}.md`：
   - `## 目标 vs 实际`
   - `## 关键指标`
   - `## 归因分析`
   - `## 风险与不确定性`
   - `## 下季度行动项`
4. **数字全部落盘。** 写完后用 `read_file` 回读一遍，确认没有占位符残留。

## 硬性要求

- 每一段都必须有数据支撑；没有数据的段落写"数据缺失：<需要什么>"。
- 归因必须区分「相关」和「因果」，不确定就标注为假设。
- 报告长度控制在 800 字以内，超出就压缩 `## 归因分析`。
