# CSV 数据体检

## 何时用

"帮我看下这个 csv"、"数据质量"、"有多少重复"、"字段对不对"。

## 工作流

1. 用 `execute` 跑 `head -5 {file}` 看真实分隔符和编码，不要假设是逗号。
2. 用 `execute` 跑 `wc -l` 拿行数，作为后续百分比的基准。
3. 按下面四类问题逐项排查，并把命令原样记录进报告（可复现）：
   - **空值**：逐列统计 `SUM(col = '' OR col IS NULL)`
   - **重复**：`SELECT col, COUNT(*) FROM t GROUP BY col HAVING COUNT(*) > 1`
   - **类型**：`schema` 对比预期类型
   - **越界**：数值列的 min/max 与业务区间对比
4. 报告写到 `/reports/audit-{文件名}.md`，每条问题带：现象、影响行数、建议动作。

## 约束

- 不要修改源数据文件。发现问题只报告，改动方案写成 SQL 交给用户执行。
- 抽样检查最多 1000 行，报告里要写明抽了多少。
